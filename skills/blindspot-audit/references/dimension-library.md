# 维度库 — 按目标类型的基础维度集

> 用途：Step 2 机制 1（维度库比对）。按目标类型拉出基础维度集，与用户给的维度求差集 → 候选补维。
> 来源：007 前端全面优化（8 维实战）、009 支付链路优化（8 维实战）+ 通用蒸馏。
> 使用原则：维度集是**起点不是上限**——机制 2/3（侦察反推、视角轮换）负责补库里没有的；每次实战发现的新维度回填本库。

## 命名约定

- 每个维度分配 2-4 字母大写前缀，专项内唯一，发现编号 `{前缀}-{序号}`（MA-1、FUL-001）
- 维度文档命名 `{NN}-{维度中文名}.md`，NN 从 01 开始
- 最后一维固定为盲区维（BS- 或 BLD-），任务书写「审计其他维度任务书未覆盖处 + 横切基建」

## 类型 A：前端 / 营销 / 公开页面（007 实战原型）

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 营销准确性 | MA | 页面数字/承诺 vs 运行时真相；可复制示例可用性（域名/模型 ID 复制即跑）；过期文案幽灵 |
| 信息架构与一致性 | IA | 导航全量图、重复/撞名入口、品牌命名统一、死链/死 span、虚构功能承诺 |
| UI/UX 交互质量 | UX | 死交互（点了没反应）、假组件（假手风琴）、断链流程（搜索提交丢弃）、a11y、响应式 |
| 多语言国际化 | I18N | en/zh key parity、双 i18n 机制并存、locale 检测与切换、半清回归（一语言清了另一语言没清） |
| SEO | SEO | metadata/title、sitemap 覆盖（博客/详情页遗漏）、robots/AI bot 策略、hreflang、JSON-LD 与可见内容一致性 |
| Geo 与地域策略 | GEO | 地域检测、币种/语言联动、目标市场可达性（字体/脚本阻断）、边缘缓存 |
| 架构与性能 | ARCH | 渲染架构（静态/ISR/动态）、缓存层、bundle 体积（全量 i18n 进 HTML 类）、营销流量直打 DB、迭代安全边界 |
| 盲点与补充 | BS | 度量缺失、内容真实性（证言/数据）、触达链路（客服邮箱）、soft-404、CI 守护缺失 |

## 类型 B：支付 / 资金 / 交易链路（009 实战原型）

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 购买入口与 Checkout | CHK | 入口全量盘点（比文档记载的多几个？）、总闸/开关覆盖矩阵、价格防篡改 |
| 支付回调与交付 | FUL | webhook 覆盖与签名、授予幂等（跨路径幂等键一致性！）、逆向事件（refund/dispute）金额与币种、交付失败兜底 |
| 订阅生命周期 | SUB | 状态机全景、续费幂等、宽限/dunning 语义承诺 vs 实现、双订阅竞态、升降级 |
| 账本与结算对账 | LGR | 账本完整性、预扣→结算→释放闭环（悬挂回收！）、过期语义（洗桶类）、金额级对账覆盖 |
| 用户侧支付页面与文案 | UIP | 计费文案禁词、金额展示口径、错误语义透传、FAQ 与运行时一致 |
| 管理后台经营面 | ADM | 管钱查账能力、纠错杠杆（能补发能扣回？）、开关描述 vs 实际覆盖面、审计日志 |
| 支付安全与滥用 | SEC | 注册/发放薅羊毛面、内部威胁（admin 发放治理）、拒付链可屏蔽性、应急阀可达性 |
| 盲区与横切 | BLD | cron/投递路径断裂、锁冲突、环境模式（test/live）与守护、合规披露（退款政策页）、FX 假设 |

## 类型 C：API / 协议 / 网关

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 协议契约一致性 | PRT | 各协议端点 vs 官方规范、透传字段完整性、错误语义映射 |
| 客户端兼容矩阵 | CLI | 各真实客户端端到端（工具循环多轮！）、会话/状态语义 |
| 路由与容灾 | RTE | 上游单点（SPOF）、fallback 链完整性与逃生、cooldown 语义 |
| 计费联动 | BIL | 每协议路径的计费覆盖（流式/图片类旁路！）、usage 提取完整性 |
| 限流与容量 | CAP | RPM/并发/全局容量三层、绕过面 |
| 可观测与对账 | OBS | 请求级审计、对账命中率（零命中=没对账）、上游成本捕获 |
| 盲区与横切 | BS | CI 是否真的在跑（死目录！）、发布欠账、配置漂移 |

## 类型 D：数据 / 存储 / 迁移

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| Schema 与约束 | SCH | 唯一索引 vs 业务幂等假设、命名与语义漂移（字段名 paymentId 实存 invoiceId 类）、孤儿列 |
| 迁移与版本 | MIG | 迁移真相源 vs journal、执行计数 vs 文件号、欠账迁移 |
| 一致性与竞态 | CON | 读后写、事务边界、advisory lock 分配冲突、serializable 需求 |
| 生命周期与留存 | LCY | 过期/归档/删除路径、留存政策 vs 实现脱节 |
| 查询与性能 | QRY | 热路径 N+1、缓存失败路径（失败不进缓存=故障放大器）、索引覆盖 |
| 盲区与横切 | BS | 备份可恢复性、跨表口径分裂、种子数据 provenance |

## 类型 E：运维 / 部署 / 发布

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 发布链完整性 | REL | 发布入口唯一性、build surface parity（app/migrate 都构建？）、验收假阴性/假阳性来源 |
| 定时任务投递 | CRN | 每个 job 的投递路径三列登记（in-process/route/cron.d）、默认关闭的调度器、parity 核验 |
| 环境与配置 | ENV | env vs DB SSOT 分裂、test/live 模式守护、NEXT_PUBLIC 构建期变量陷阱 |
| 监控与告警 | MON | 健康端点覆盖、告警接线（breaker 有没有接 webhook）、静默失败面（console.error 后回 200） |
| 回滚与应急 | RBK | 回滚路径演练过没有、应急阀（kill-switch）on-call 可达性 |
| 盲区与横切 | BS | 文档 runbook vs 实态漂移、marker 文件失真、灰度与生产差异登记 |

## 类型 F：安全专项（可独立成专项，也可作为其他类型的一维）

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 认证与会话 | AUTH | 凭证生命周期、server-only 属性泄漏、CSRF/Origin |
| 授权与 RBAC | RBAC | guard 覆盖计数（新路由登记了吗）、能力矩阵 vs 角色实态、豁免清单 |
| 输入与注入 | INJ | 验证 schema 覆盖、透传字段风险 |
| 滥用与薅羊毛 | ABU | 发放面盘点、节流、一次性邮箱/多注册、关门信号监测 |
| 数据暴露 | EXP | 用户面遮罩（key/ID）、内部命名空间泄入 HTML、日志脱敏 |
| 盲区与横切 | BS | 依赖 CVE、密钥轮换、审计日志完整性 |

## 通用横切维（任何类型都应检查是否需要）

- **度量与可验证性**：目标域有没有度量？没有 → 改进无法验证，本身是 P0 级发现（007 BS-1）
- **CI/回归守护**：关键口径有没有测试断言守护？「文案半清回归」「计数守门」都是这一类；守护还要查**咬合力**——在跑 ≠ 会拦（008 BS-1：CI 常红+触发面缺口="在跑但不咬人"；105：子目录 workflows 从未执行）
- **文档与口径漂移**：对外承诺（Terms/FAQ/README）vs 运行时实态
- **触达链路**：用户能不能真的联系到你（邮箱/表单/工单的端到端可达性）——但注意误报防御（本机 DNS 不可信）
- **视觉资产敏感值**：截图/图片里的 key/UUID/邮箱/内部数据——文本 grep 扫不到，必须逐张读图机扫（008 LEK-1 实锤：全场最重 P0 是截图里的真实 API key）

## 类型 G：文档 / 知识库（008 实战原型）

| 维度 | 前缀 | 审计焦点 |
|------|------|---------|
| 内容准确性 | ACC | 数字/机制描述 vs runtime SSOT、幽灵文案（已删机制仍在宣传）、域名/URL 口径 |
| 覆盖度与能力缺口 | COV | API/能力全景 × 文档覆盖矩阵（实现没写/写了没实现）、鉴权类型与文档声称一致性 |
| 使用者旅程可用性 | USE | 分受众旅程走查、示例复制即可跑（域名/模型 ID/参数枚举）、内链完整、排错出路 |
| 文档 UI 交互 | DUX | 导航/搜索/代码块/语言切换/soft-404/暗色/payload |
| 内部信息暴露 | LEK | 禁词表扫描、内部架构泄漏、**截图逐张机扫**、对内文档混入 |
| 双语一致性 | I18 | 机械校验实跑 + 内容级 parity（章节/代码块/数字逐对）+ 术语统一 |
| 可发现性 | SEO | sitemap 覆盖/metadata/canonical/hreflang/llms.txt/raw 端点 |
| 盲区与横切 | BS | 守护咬合力、零度量、doc↔code 一致性工具实态、changelog 结构、发布时滞 |
